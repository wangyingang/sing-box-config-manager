# 共享节点库采用固定修订引用

2026-11-02，用户确认首版建立共享节点库，多份 Recipe 引用固定节点修订。节点具有独立身份和不可变修订；Recipe 保存节点修订引用及本地出站 tag，解析后才交给 Compiler。这样可以统一维护节点连接信息，同时避免节点更新静默改变已有 Recipe 和发布版本。

本决策取代初稿中“节点内嵌在各 Recipe、复制后独立维护”的建议。共享范围按后续确认的[统一管理模式](0002-admin-managed-configurations.md)执行：由管理者维护，允许不同配置使用者的 Recipe 引用；原草案的 same-owner 限制不再适用。新节点修订必须经显式引用升级、新 Recipe 修订及重新发布后生效。

2026-11-02，M2 访谈 Q4 确认：归档禁止新增引用，已有 Recipe 仍可使用其固定修订重新生成和发布；被引用的修订不能删除。要使现有 Recipe 停止使用节点，需显式改绑并重新发布。归档不撤销设备已经下载的配置。
