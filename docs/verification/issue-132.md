# #132 规则集运行时与测试准备联合验收

本次复用版本选择和保留历史测试的准备结果。同一测试文件中，每种配置与分支布局先从空状态调用生产 `sync` 等服务，用真实 sing-box 生成候选和稳定交付。每个场景再从该状态创建自己的仓库、配置、上游历史和时钟。原生验证证明和固定地址下载缓存继续由生产代码在每次操作开始时创建。同一场景中的并发会话共用该场景的可变 Git 和上游。对应 [#132](https://github.com/wangyingang/sing-box-config-manager/issues/132) 和 [Spec #124](https://github.com/wangyingang/sing-box-config-manager/issues/124)。
