# Triage labels

工程 skills 使用以下五个 canonical roles。本仓库的标签名称与角色名称相同。

| Canonical role | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent 自主实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予实施 |

Skill 引用某个角色时，使用表中对应的本仓库标签。
