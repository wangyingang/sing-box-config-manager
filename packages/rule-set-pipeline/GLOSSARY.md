# 规则生产

将系统维护的外部规则转换为可供配置编译使用的版本化匹配集合。

## Language

**Rule Administrator（规则管理者）**：负责定义系统规则集、选择来源和控制交付版本的人。

**Subscription Consumer（订阅使用者）**：通过配置引用系统规则集并取得交付内容的人或客户端；不因此获得规则源管理权限。

**Rule Source（规则源）**：规则管理者维护的外部规则输入及其解析语义。订阅使用者不能通过 Recipe 自行添加规则源。

**Curated Rule Set（系统规则集）**：由管理者赋予逻辑身份、可供订阅使用者选择的独立匹配集合。同一逻辑身份可以更换来源；来源中的列表名不等于系统规则集身份。
_Avoid_: 分类目录、父规则集

**Rule IR（规则中间表示）**：来源语法解析完成后、生成目标产物前的最小匹配语义。不包含路由或 DNS 动作。

**Rule Artifact（规则产物）**：一个规则集版本交付的一份逻辑产物，同时以 JSON 和 SRS 提供相同的匹配内容。
_Avoid_: Config Recipe、客户端配置

**Artifact Manifest（产物清单）**：记录规则集版本以及各格式文件的地址、长度和内容摘要。

**Conversion Report（转换报告）**：记录规则转换结果、被跳过的内容及构建失败原因的报告。

**Rule Subscription（规则订阅）**：通过稳定地址获取规则集当前交付版本的 JSON 或 SRS 文件。

**Rule Candidate（规则候选）**：为一个系统规则集保留的构建及其证据，可以处于未完成、失败或验证通过状态。存在候选不表示已经交付或可以被选用。

**Active Rule Version（当前规则版本）**：系统规则集目前通过规则订阅交付的版本。它可能来自旧来源，不表示期望来源已成功采用，也不表示所有客户端已经加载。

**Desired Rule Definition（期望规则定义）**：管理者指定的规则输入、筛选条件、产物名称与发布路径，独立于当前实际交付。

**Input Binding（输入绑定）**：规则集对实际来源、获取与解析方式及所选列表的绑定。不包含来源别名或上游后续发布版本。

**Rule Update Control（规则更新控制）**：一个规则集处于自动更新（auto）或人工固定（pinned）的决定。固定同时选择交付版本并停止该集全部上游自动处理。
_Avoid_: 双暂停

**Rule Delivery（规则交付）**：将已验证版本提供给稳定订阅入口的结果。交付成功不等于客户端已经加载。

**Rule Build Record（规则构建记录）**：关联固定来源、构建过程、产物及验证证据的追溯记录。
