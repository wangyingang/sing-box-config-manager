# 规则生产

将系统维护的外部规则转换为可供配置编译使用的版本化匹配集合。

## Language

**Rule Source（规则源）**：系统维护的规则输入及其解析方式。用户不能自行添加外部规则源。

**Curated Rule Set（系统规则集）**：系统维护、用户可选择的独立匹配集合。不同来源的同名集合仍是不同集合。
_Avoid_: 分类目录、父规则集

**Rule IR（规则中间表示）**：来源语法解析完成后、生成目标产物前的最小匹配语义。不包含路由或 DNS 动作。

**Projection（用途投影）**：从规则集合中选出适合特定使用场景的匹配条件。项目区分 Route、DNS 请求域名和 DNS 响应 IP 三种用途。

**Rule Artifact（规则产物）**：一个规则集版本面向特定用途生成的具体规则文件。
_Avoid_: Config Recipe、客户端配置

**Artifact Manifest（产物清单）**：描述已发布规则产物、来源版本、内容摘要和使用约束的记录。

**Conversion Report（转换报告）**：记录规则转换结果、被跳过的内容及构建失败原因的报告。
