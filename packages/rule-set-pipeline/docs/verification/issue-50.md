# Issue #50 立即检查验收

[工单 #50](https://github.com/wangyingang/sing-box-config-manager/issues/50) 的公开入口是 `checkRules` 和 CLI `check-now`。验收使用 sing-box 1.14.4、受控官方 Release 响应和内存 Git transport，分别覆盖单分支和双分支布局。

| 场景 | 可观察结果 |
| --- | --- |
| 同批次只改变 Anthropic | 单次查询 Release 和资产。候选总数只增加一个，只有 Anthropic 增加激活历史。其他集记录本次实际检查的 Release。 |
| 单集转换失败及共同输入损坏 | 单集输入或当前激活记录损坏时兄弟集成功交付。摘要校验失败时稳定入口无写入。下一次正常检查重试失败集。 |
| 来源定义与订阅约束变化 | 同字节的换源定义重新构建并激活。与当前交付不兼容的 v2 订阅被拒绝。 |
| 两类人工固定 | 回滚固定跳过该集的自动重试和激活。人工指定允许发布候选，稳定入口继续交付指定版本。 |
| 候选完成后中断 | 从新目录复验远端证据并继续尚未完成的激活，候选 ID 不变。显式重建仍只写候选。 |
| 切换未提交、切换回复丢失 | 确定未提交的切换可重试；已提交但待核实的切换报告当前版本。换机后核实已提交记录，无重复切换。 |
| 并发人工固定或维护 | 在来源下载或自动激活登记后插入人工固定，并在来源下载中切换维护代次。旧任务无法把候选或稳定文件追加到新 head。 |
| CLI 结果 | 逐集 JSON 保留暂停和待核实结果。正常暂停退出 0，待核实退出 1。 |

原生测试在 `test/integration/check-now.test.ts`，CLI 入口测试在 `test/cli.test.ts`。使用仓库根目录的统一验证入口 `node scripts/verify.mjs --out <新证据目录> --binary <1.14.4 绝对路径>`。实际产物分支、CDN 传播和定时触发由后续隔离验收覆盖。
