# 配置管理

管理用户配置意图、发布过程和配置交付，不承担规则转换或配置组合。

## Language

**Administrator（管理者）**：统一维护节点库、Recipe 和配置交付的人。首期由项目使用者本人担任。

**Recipient（配置使用者）**：使用某份配置的人，可以是管理者本人、家人或朋友。配置使用者不等同于管理账号。

**Recipe Draft（配置草稿）**：管理者正在编辑、尚未成为有效发布版本的 Config Recipe。已保存草稿结构完整，但可以存在未解决的语义诊断。

**Recipe Revision（配置修订）**：一次固定的配置意图记录。继续编辑产生新的修订，不修改已有发布所使用的内容。

**Node Library（节点库）**：由管理者维护、供不同配置使用者的 Recipe 选择并复用节点的集合。共享维护节点不意味着自动更新所有引用。

**Node Revision（节点修订）**：某个节点在一次固定版本中的连接信息。Recipe 引用具体节点修订。

**Archived Node（已归档节点）**：不再允许新增引用、但已有固定引用仍保留的节点。归档不等于撤销已交付的配置。

**Publication（配置发布版本）**：固定输入及校验结果后生成、可供交付的配置快照。
_Avoid_: 配置草稿、规则产物

**Active Publication（当前发布版本）**：某个配置交付目标当前选择的已通过校验的发布版本。

**Subscription（订阅）**：可撤销的配置获取授权及其交付目标。订阅身份与管理者登录身份分别管理。

**Delivery Target（配置交付目标）**：关联配置使用者与 Recipe 的交付对象，使用 Recipe 已固定的 Client Profile。设备可关联交付目标。

**Generation Parameters（生成参数）**：在已声明范围内影响一次配置交付的参数。首期仅包含可信入口提供的 ECS 参数。
